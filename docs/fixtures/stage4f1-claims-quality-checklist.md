# 4F 合成材料与人工质量验收清单

## 使用范围

同目录 stage4f1-claims-synthetic-input.json 是唯一四字段输入；纯合成防护罩案例，不对应真实客户/设备，不是实施安全建议。上游文件不选择，附件上传为 0；材料未发送给任何模型。此清单只作人工评阅，不随四字段发送，不是期望输出答案或新的验证器。

正式调用前在原生页面核对实际模型、提供方及材料接收方、四字段正文、flow-2-6/0.2.1、费用上限和最多一次调用。JSON 文件是便于固定内容的夹具，不宣称 UI 已支持直接导入；各字段通过既有四选项卡填写。不得在材料中配置凭据。

## 评阅（每项记录通过/缺陷/待人工判断及对应权项）

1. 形成中文编号权利要求初稿，而非只有建议或模板；不超过用户要求的 6 项，不强行凑数。
2. 独立装置项交代相关部件、信号来源和控制关系；不把必需的双信号联锁写成任选其一。
3. 保留开罩先停机、停止后解锁的技术关系；若置于从属项，检查其布局依据及对主技术问题的影响。
4. 从属项有引用基础且增加限制，不能取消被引用项的技术限定；故障指示仅按 F-07 的已知条件写入。
5. 特征矩阵能定位 TP-01、TS-01、F-01 至 F-07 与 TE-01；不得把 Skill 教学案例当成本项目事实。
6. 锁销尺寸、传感器冗余、失电状态、停止阈值等未提供事实不进入确定性条款；如提出候选补齐，须具体标记并登记人工待确认。
7. 不编造实验比例、检索文献、说明书段落号，不声称已读取图像或上游文件，不声称已核验新颖性/创造性。
8. 输出结构经现有解析器接受，累计稿明确上游缺失，保留实际输入、结果、矩阵、回退及风险。结构成功不替代上述内容评阅。
9. 使用者确认草稿可作为后续人工修改基线；不将其视为可直接申报、获授权或设备安全认证。

## 判定与后续

有无来源关键特征、错误联锁关系、虚假证据或无正文等实质缺陷时不通过。人工结论未取得时仍待验收。记录具体问题，不使用测试数量替代质量评价。

4G 复用同一运行：编辑→审核失效→再审→无覆盖保存→原生打开→重启恢复→准备正确 Workspace 的固定版本对话草稿，不发送。若修复导致需新模型结果，另行授权，不能自动重试。
