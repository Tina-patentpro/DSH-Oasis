## 实施步骤与合同
1. Host 只读适配：固定生产 origin，复用账户凭据捕获；分页查询 folderlist、projectlist、files。详情校验项目/账户归属；资源 API projectId 必须与所选项目 ID 的字符串表示一致，否则不展示为可导入。legacy 与资源式 API 分开解析；接口缺失明确显示，不用空列表冒充完整。
2. 导入服务：当前 Workspace 的权威路径；限时选择令牌冻结账户修订、项目、文件清单及本地目录；提交只接收令牌和选中键，不接受客户端 URL 或绝对路径。每次最多 100 项、单文件 32 MiB、总量 100 MiB。历史正文存为 _OIW.md，附件保留扩展名，安全文件名校验；同名同内容跳过，不同内容增加序号，无覆盖。逐项独占写入，持久化追加式清单记录意图/完成/失败，中断文件不冒充完成。拒绝重解析路径、身份变化、过期令牌；同一项目只允许一个导入提交。
3. 项目关联：原生设置保存 origin/account/folder/Workspace/path 映射；冲突时不替换。关联不等于已验证专业服务/schema，不推测服务 ID，也不新增手填绑定表单。
4. Client 弹窗：功能中心入口，应用内复用账户登录；项目搜索/分页/子项目浏览；正文/文件勾选；目标目录、数量、限制、关联提示；显式提交、逐项结果、原生文件管理入口。切换项目/账户丢弃晚到响应；无挂载即自动下载；不渲染网站原始 HTML 或缩略图。
5. 验证：先新增失败用例，再实现适配、写入与 UI；复用既有隔离 source-promotion 构建副本，不新增运行环境。完整 verify 后才同步 lib。安装/真实登录与下载另列人工验证，不把离线测试视为生产通过。
