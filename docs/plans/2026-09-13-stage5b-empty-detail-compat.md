# 5B 原 API 空占位兼容（已批准）

目标：仅在 POST /api/apicategories/apidetail 的成功响应进入通用检查前，对详情对象直接属性 api_key、credentials 的 null/空字符串值作无副作用剔除。其他拼写、值、嵌套层级、接口、请求继续拒绝。共享检查器与 normalizeApiDetail 保持严格；其 raw 只接收清理后的数据。

用户已明确同意实施。无 OpenSpec 目录，本文作为等效范围记录。修改 oasis-api-contract.js 及定向测试；不改服务器、共同四字段、绑定、生成入口或发行包，不调用收费生成、不安装、不提交。

步骤：先补测试并观察既有代码失败；实现一处端点限定的响应清理；运行相关合同回归；匿名只读取得已核实详情响应后，在本地通过真实客户端解析链复验，不向远端发送测试凭据。出现非空秘密或合同漂移即停止，不输出值。

验证：空值组合/无占位/有无 data 包装、原对象不变、raw 无占位、非空和异型值拒绝、嵌套和变体拒绝、其他接口拒绝、请求拒绝。只读现网样本不等于真实 Profile JWT、Desktop 或完整生成验收。输入映射另批。
