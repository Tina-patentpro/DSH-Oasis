2026-11-12，北京时间。范围是绿洲慧写 15 个独立 Skill，以及中国专利总路由和 9 个子 Skill，共 25 个入口。准备件包括 25 个主用例、7 个变体、12 份公开原件或自编合成材料、逐项验收判据和同版输入摘要。此计划承接 DS-02/05，先用隔离 DSH 工作区取得具名结果。执行由 Codex 单代理推进，逐组按 EXEC-R2 核对。

## 一、测试对象与现有接点

当前只读核对的是 DSH NEXT 2.0.22-next 与绿洲工作台 `0.1.0-rc.5.next.10`。活动包以 `m06-next-merged-host.js` 进现有 Host。14 个 V3.4.0 节点已有共同输入字段。真实本地确认及派发仍限定 Flow-2-6，离线入口也有明确的 M06 范围。上次在当前安装完成的两次真实生成分别绑定内置绿洲 M06 `0.1.3-public.1` 和中国专利的两份权利要求资源，可复用为原范围控制样例。公开绿洲 M06 `0.3.0-rc.4` 及中国专利完整申请流程仍是独立受测对象。

**选用的准备路线。** 绿洲 M01—M14 复用现有节点及共同表单，逐项确认资源与字段的无损对应。在旁置候选里补绑定，再验同页、审核、保存和恢复。I01 的预期是实际图件及标号核对，需具名图件合同。中国专利先验证总路由和只读资料装配，逐子 Skill 核原能力所需的具名工具与产物。只在原 Host 合同允许的接点扩展，整套上游所需的任意脚本、网络或多步执行与当前一次模型调用范围有差异，需先确认具体测试候选和工具用途。

备选是只在独立 DSH 测试会话验证上游包的路由和工具行为。该路线可早取来源能力证据。若采用，使用空测试项目、获准的公开 DSH 接口及固定工具能力，独立标注结果，仍需补绿洲工作台入口与产物验收。当前准备文件适用于两种路线，首批建议走绿洲工作台的文本节点。

## 二、准备好的材料与执行方式

1. 单项以 `cases.json` 的明确 ID 开始。只将该项 `fields` 和 `attachments` 声明的材料按相对路径放进测试 Workspace，按 `section` 指定的边界提取文本，原文件仍留在冻结目录。把本项 `request` 与通用测试说明合并进 `user_input`。标有 `_file` 的字段读完整文件。变体沿主用例，仅覆盖显式字段并移除 `remove` 指定的输入。总路由的每条 `probes` 独立输入。用例说明和下方验收判据由审阅方持有。
2. 默认独立节点测试，`upstream_md_file` 留空并核对产品对前序缺失的说明。链路测试另起一轮，只使用立即前序实际输出，核对其版本和摘要。按现有项目归属、文件读取和预览规则操作。外部服务只接受明确选定的测试查询或公开源。
3. 预检先记录套件、资源、Host、Workspace、输入 SHA-256、请求标识、模型和工具许可。禁止重用旧确认。预检用替身核一次派发、改动失效、越权与无覆盖保存。真实批次经同版预检和当批授权后执行，每项最多一次。失败或未知保留原请求，只观察原运行。
4. 回执逐项记实际模式、开始/完成、模型/工具调用次数、正文及文件摘要、审核版本、保存与重启恢复结果。报告分别记材料、装配、离线、真实生成、真实工具、专业审阅和费用证据。工具或格式缺项落到对应行。工作台结果仍使用共同的预览、编辑再审、保存与固定版本引用。引用准备为未发送草稿。

现有 690 字节交底和 851 字节附图已按 11 月 11 日回执逐字节复制。新增合成材料含两方案、明确的 TRIZ 预期效果、待确认访谈、权项 A/B、带预置差异的说明书、对照全文、模拟审查意见、发明申请正例及两份测试库笔记。发明材料通过上游申请门，空目录按预期缺交底。上游扫描工具读到两份测试库笔记和一条引用关系。另准备一页美国国家档案馆公开附图 PDF，离线解析提取 107 个文本字符，供扫描版读取能力单独验证。著录查询入口在准备时超时，真实检索仍待实测。 [美国国家档案馆原件](https://www.archives.gov/files/historical-docs/doc-content/images/edison-patent-light-bulb.pdf) · [国家知识产权局公告入口](https://www.cnipa.gov.cn/col/col74/index.html)

## 四、执行顺序与每批出口

- [x] **准备件。** 冻结公开材料、受测源包和用例字段，完成逐项清单与材料门检查，交付本文及配套文件。
- [ ] **旁置宿主。** 在实际 NEXT 源码工作树先核未提交变更及装机差异。用现有 `src/v340-catalog.js`、`src/v340-preparation.js`、`src/v340-native-model.js`、`src/v340-runtime-service.js` 与 `src/workbench-rpc.js` 核资源和调用边界。保存既有 M06 实际身份，按准确版本完成 M05 的 SKILL-1 输入、输出和资源绑定，再完成 M01、M02。使用隔离 Profile 和单一写入者，候选未过确认与结果恢复测试时不启用对应动作。定向复用 `test/v340-native-all-nodes.test.mjs`、`test/skill-suite-settings.test.mjs`、`test/dsh-next-offline.test.mjs` 及相应原生离线入口。
- [ ] **首批文本实测。** 建议顺序 M05、M01、M02，沿 `cases.json` 冻结三个请求。只有在旁置宿主实证输入不超过 32,000 token、输出上限 16,384 token、无工具和无自动重试，且用户批准本批范围后，才按建议模型 `deepseek-official / deepseek-flash / Low` 派发。按 11 月 12 日官方高峰费率，三个请求按全未命中计算上界约 ¥0.59，建议批次上限 ¥0.60。任一上限不能在实际请求中核实时，先重算报价。每项仍取实际用量和可取得的账单。 [DeepSeek 官方费率](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
- [ ] **其余文本及总路由。** 按资源绑定、输入前置和保存恢复分组接通剩余 Oasis 文本项，优先复用已验的 M06 控制用例。中国专利总路由先验 12 个意图和拒绝条件，再按实际子包对接。保持项目归属校验、来源切换确认失效和未知作业防重。工具不足时给明确的能力缺项。
- [ ] **工具与格式。** 先验证纯本地材料门、只读测试库和隔离写入，再分别接入 PNG/SVG、DOCX、公开检索、PDF 与地图渲染。申请图件／Word、外部站点、向量模型须各交具名权限及实物。现有 DSH 文本版和格式准入沿原 DS-03 证据，重大工具扩展及对外请求按其具体用途办理。中国专利审查答复的副本差异由固定源码候选单独复核。
- [ ] **收口。** 以 25 个主入口核已跑、失败、受阻及未覆盖的变体。本文只覆盖本地 Skills 专题，V3.4.0 的专业 API 双来源、R7-03 原稿采用、正式发布及 29 项产品目标继续各按原工作包验收。
