## 1. 结论

第三周在批准的本机隔离范围内完成关闭。技术研发与中国发明专利两类工作流均已形成“选择工作流 → 编辑 schema 表单 → 登记项目材料 → 创建不可变输入快照 → 生成 local-mock → 预览 → 人工审核 → 安全写回”的可复核闭环；本轮没有未解决 P0～P2。

本结论只证明当前机器、当前仓库、固定 DSH 版本和 loopback 临时 Profile 的本地闭环，不证明 DSH Desktop 正式产品环境、生产部署、真实模型或外部专业服务质量。Dify 与收费系统未被调用、修改或重新验收。

## 2. 已验证的产品行为

1. 工作流选择在原任务页原位转换为输入、材料和结果区域；技术研发表单 5 个字段，专利表单 6 个字段。
2. 材料必须位于当前 Workspace，使用相对路径；Host 在登记前后核验路径身份、文件类型、大小和 SHA-256，拒绝链接、目录、越界、TOCTOU 变化和超预算输入。
3. 材料字节只在本机以流方式计算哈希；正文不被提取、不持久化，也不参与本周 local-mock 生成。界面与产物已如实披露该边界。
4. 每次运行保留不可变输入快照、工作流版本、mock 版本、内容状态、风险、问题清单、人工审核和写回记录。
5. 专利工作流存在未确认事实时返回 `blocked`，不能批准或写回；补齐后生成新的 `warning` 运行，旧运行仍保留。
6. 写回分为预演和确认两步，确认令牌仅存 Host 内存；只允许 Workspace 内新相对路径，以排他创建实现默认不覆盖，并在发布前重新核验父目录与冲突。
7. 浏览器验证保持 DSH 原生 sidebar、conversation 和 details 节点身份；normal、expanded、hidden、原生 details 与窄屏状态均未替换原生节点。
8. Client 卸载先冲刷已知 Workspace 的待保存草稿，再清理监听器、布局与 Portal；Host 卸载释放 RPC 和工具注册。
