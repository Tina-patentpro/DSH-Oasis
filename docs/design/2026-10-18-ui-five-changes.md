1. 结果版本标签支持双击行内改名。Enter提交、Esc取消。每张标签右上角有叉号；点击意味着删除该版本及其保留内容，不只是关闭视图。正在生成的版本仍按运行锁定规则处理，不借删除标签取消后台运行。
2. skill有DSH模型选择框，且没有“大模型”前缀；专业没有模型或服务选择框；两者均没有标注中的非模型选框。
