## 本批范围

1. 通过固定方法与固定路径调用已冻结的九个用户端端点，不允许调用方覆盖路径或重试策略。
2. 上传前重新核验已确认项目材料；文件正文只在 Host 内存中短暂读取，不进入 RPC 或持久化状态。
3. 创建请求前持久化输入、服务、文件夹、价格和材料快照；同一请求 key 最多发起一次创建。
4. 创建结果未知时只允许使用原请求 key 查询对账，不自动重复创建；本地等待有界且可以停止。
5. Client 只接收严格校验后的安全目录、服务定义和 Host 权威状态；JWT 只能由 Host 凭证服务按操作解析。
6. 工作台动态渲染 Host 返回的输入字段，并要求价格确认和外部材料传输确认。

## 非目标

- 不调用真实或生产 API。
- 不配置、记录或展示真实 JWT。
- 不下载远程结果文件，也不把远程 URL 宣称为已验证文件证据。
- 不进行 DSH 浏览器或安装后运行验证。

## 停止条件

- 可信文档哈希变化。
- 目标来源归一化为生产域名。
- 服务 schema、文件夹、价格、余额或材料完整性在提交前变化。
- 创建结果未知时禁止再次创建；转为原 key 对账。
- RPC/持久化响应不能通过严格 schema 或完整性哈希。
