## 已验证的不变量

- 上传与结果 URL 必须来自非生产来源；API 基础来源与完成运行快照一致。
- 远程执行输入哈希由服务、文件夹、价格、表单和材料快照共同计算并在读取时复核。
- 已上传文件必须对应已确认材料及其 SHA-256；文件字节不持久化。
- 创建调用结果未知时不会重复创建，只按原 request key 查询。
- Client 无法向 RPC 注入 JWT、Host 证据、端点覆盖或额外字段。
- 目录失败不会阻断既有本地工作流；远程能力在未配置时显示为安全禁用。

## 尚未验证的风险

- 真实非生产服务的字段、响应延迟、异步进度与文档是否完全一致。
- DSH 安装后 Host、浏览器和凭证界面的端到端行为。
- 远程上传接口在响应丢失情况下是否具备服务端幂等性；本实现不把上传成功当作已验证，且创建仍保持单次约束。
