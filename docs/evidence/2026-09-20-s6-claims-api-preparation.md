## 实现合同

新增精确 POST/RPC `task/prepare-api`，仅接受 Workspace、task 及显示的业务/设置 revision。Host 读取同一份权利要求 v2 草稿，复用 `claims-api-document.js` 的 UTF-8 TXT 和四字段映射。客户端不能注入正文、绑定、输入哈希或上传 URL。

返回分离的准备快照：Workspace 路径、完整绑定、两个 revision、模板/来源/输入版本、四字段原文、映射 revision、文档字段/文件名/字节长度/SHA-256、映射后的文本字段及文件 URL 允许来源。`allowedUploadOrigins` 指允许接受的上传返回文件 URL 来源，不是新的材料上传目的地址。

`preparationSha256` 绑定上述准备内容，重复读取稳定，账户/目录/服务/schema、设置 revision、输入变化都会改变。它不是凭据快照、认证证据、上传回执、持久运行标识，也不是调用授权；不修改旧运行哈希。

缺少/跨 Workspace 绑定、Workspace 根变化、origin/environment 变化、旧 revision、错误模板/来源、空技术交底、非法 Unicode、额外文件/上游材料、未结束生成均拒绝。源对象与响应不共享可变引用，旧结果/审核/回写不变。

响应固定 `status=unverified`、`canSubmit=false`，明确列出绑定、文档服务合同及执行接线未完成。保存的旧 schema hash 不能证明 TXT 和省略其他字段已被真实服务接受。不开放 UI 来源，不进入 legacy start/continue，不读材料文件，不读取凭据，不上传/创建/轮询，不写原生设置或业务存储。
