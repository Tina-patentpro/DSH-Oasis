## 2. 产品范围

- 本项目是基于 DSH 的专业业务插件与受控 Desktop/Sidebar 组合，不是新的通用工作台。
- 充值、消费记录、账单、退款查询等辅助功能留在已有网站；插件只保留必要的本次费用/余额提示与系统浏览器入口。
- DSH 负责模型、原生任务、Skills 执行基础、会话、权限、凭据和基础服务。
- anywhere-labs Desktop 与 Better Sidebar 可以按需求二开，但先用现成配置/插件/公开扩展，确有缺口再做小型通用补丁。
- 专业业务逻辑只在绿洲插件；不塞进 Desktop、Sidebar 或 DSH 核心。
- 不重复实现通用聊天、文件管理、编辑器、布局、Agent 循环、调度器或账务系统。
- 测试是交付证据，不是业务进度。不得继续扩展旧诊断器、监管器、N3 或自动审计工具链。
- 先交付一个模板的双来源文字生成→审阅→保存 Markdown→DSH 对话使用，再复用到另一个研发/专利模板。首版已选权利要求初稿（flow-2-6）；新增模板须明确合同，不从示例静默推定，也不静默缩减整体目标。
- 材料登记/哈希不等于正文参与生成；文件 URL 不等于文件已交付；专利受理/提纲不等于完整申请文件。首版文本以外能力另列后续切片。

## 5. 两种生成方式必须共用界面和结果规则

- 正式来源只有“本地 Skills”和“专业 API”，通过同一个分段开关切换。
- 同一业务模板使用同一 inputSchemaVersion、一份草稿、相同字段/顺序/校验、同一提交/进度/结果组件。
- 不保留两套本地/API 面板，不把本地方式变成让用户去聊天输入不同命令。
- API 特有字段由适配器和已确认项目绑定提供；不能为了切换而增加第二张表单、静默丢弃输入或编造默认值。
- 无法无损映射的模板禁用相应来源并说明原因，不伪装为已支持。
- 来源开关不发请求；运行中锁定输入/来源；变化导致费用/外传确认失效。
- 不在失败后自动切换来源或自动重发不确定的创建请求。
- 两类产物使用同一预览、编辑后再审、审核、版本、保存、导出、引用及权限规则。
- 复用既有内容寻址 artifact；共同数据合同不强迫两端生成相同正文/章节。未返回 risks/questions 等必须标未评估，不用空数组伪装无风险。
- API 绑定记录固定服务与 schema/映射指纹；实际语义或必需字段变化时禁用该模板来源，不静默修改共同表单。
- 来源只用于追溯、费用和隐私说明；不得按来源给内容不同等级、跳过审核或剥夺操作能力。
- local-mock 仅测试/历史兼容，不能作为真实 Skills 能力宣传。

## 7. 设置、文件与对话复用

- 所有项目配置都进入 DSH 原生设置页面；一个设置只有一个权威 owner/存储。
- 专业 API origin 随版本固定，不提供环境/地址/JWT输入。使用网站相同的手机号验证码或密码登录，由 Host 取得并交给 DSH credentials 保存；不自动沿用旧手填 JWT。退出仅清本插件账户，不连带退出网站。
- 模型/凭据使用 DSH 原有设置，桌面/布局使用 Desktop/Sidebar 原有设置；绿洲不复制一份。
- 绿洲原生设置页仅保留使用说明与账户登录/退出；不再提供“启用本地 Skills 真实模型生成”选框或“当前项目 API 绑定”区域。正式模式按DSH原生能力可用性挂接生成，不受旧localModelEnabled=false控制；每次生成的数据/费用确认仍保留。删除绑定UI不等于允许猜测网站folder_id或取消项目归属校验，接续规则须有明确业务决定。
- 绿洲工作台仅保留配置状态及设置入口；本次上传、费用与审核确认仍在业务流程中。
- 项目身份必须由权威 Workspace/Session 上下文解析；后台 folder_id 与 API origin/账户共同显式绑定，不按同名或 ID 单独猜测。
- 设置区分 DSH Profile、Workspace 与本次任务；新任务固定默认本地 Skills，专业 API 由用户在任务中选择，已有任务保留选择。不设置绿洲独立保存目录；两类新产物同存当前项目根目录，Skills 文件名无来源标记，API 文件名在扩展名前加 _OIW。旧文件不自动改名/移动。草稿持久化并检测并发 revision 冲突，首版每 Workspace 最多一个活跃生成。
- 改变 origin/账户使旧目录、项目绑定与确认失效，不把旧 JWT 自动发送到新地址；运行配置冻结，不中途改目的地或账户。
- 使用 Sidebar 的文件打开/编辑/预览与原生引用接口；不模拟点击或读私有 store。
- “引用当前文件”与“使用固定审核版本”明确区分；文件变化后不得沿用旧审核结论。
- 产物列表/读取工具只读当前项目并按需分段；不接受任意跨项目路径，不返回凭据。内容哈希不是权限：相同哈希跨项目仍必须校验归属。
- 复用宿主安全预览，生成正文/文件/引用视为资料而不是系统指令；不执行原始 HTML/脚本或自动加载远程资源。
- 引用只准备对话草稿/资料，由用户发送；不得自动启动生成或费用操作。
- Tab 是视图，关闭不等于取消任务；切换和晚到响应不得改变任务的项目归属。
