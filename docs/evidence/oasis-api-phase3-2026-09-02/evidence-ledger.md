## 已验证的不变量

- 本地与远程完成结果使用不同预览合同；远程 URL 明示“未下载、未验证”。
- 远程写回仅接受已人工批准的权威 artifact，且继续使用新目录、无覆盖、单次令牌、暂存校验和最终单次重命名。
- 远程 `.oasis.json` 不包含原始 request key、价格、凭证、绝对路径或 artifact 正文。
- `recordId` 由创建/查询响应进入 Host 执行账本；缺失时直接返回 `unverifiable`，不发流水请求。
- 流水只在用户按需触发时读取，不进入工作台 Domain 记录；当前页未命中只返回 `not-observed`。
- Client 严格校验观察响应，且只为当前选中的已完成远程运行展示绑定 `runId` 的结果。
