2. **锁止特征在终版节点被删除。** 核心独权 `1729852685877`、完善节点 `1741410582291` 和整合节点 `1730359104417` 的原文均保留“底座上设有锁止件”。终版节点 `1728183992412` 的原始输出已删除它，之后规范化及投影未再改变该事实。其实际提示允许“若无法在输入资料中找到足够支撑，则删除或收窄该功能/效果片段”，并以高优先级闭环为硬门。由此可解释本次删除发生的位置与提示机制；终稿只剩底座、导向槽、滑块，仍须专业决定如何保留和表达资料不足的核心方案，不能因无新增事实就判为完整成果。
