## 用户现在能完成什么

- 在同一四选项卡页面选择当前 Workspace 内的一个上游 Markdown，确认后冻结来源、正文及 SHA-256；切换两来源不丢输入。
- 使用公开本地离线来源或 API 合成来源，生成包含完整上游、实际输入、当前结果、更新记录及继承风险的累计文稿。
- 编辑后重新审核，保存到新目录，以 Sidebar 原生文件预览打开；重启后恢复输入、文件选择和版本。
- 原文不会因模型建议被删除。替换要求用户指令独立一行 `替换：内容ID`、唯一来源定位且范围不重叠，原始基线与修订记录仍保留。这是程序条件检查，不证明替换在专业语义上正确。

真实 API 尚未接通本切片；“本地”使用原生 llm 服务的公开离线 Provider，不是付费模型或私有 Skill 的实际生成能力。
