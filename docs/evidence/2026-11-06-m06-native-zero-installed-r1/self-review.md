# 单代理技术自审

范围为本版控制器小改动、另版安装候选及离线证据，不冒充独立审阅或专业/用户接受。

- 策略校验先于建根；四项预算必须全为0、guard key 精确匹配且 hash 命中当前业务组件。原无策略模板不加零生成标记。
- 启动规格与后续启动共用实际 installed writer 路径；回调期间两层租约有效，结束及异常均释放。规格的 cwd 和 DSH_HOME 分别指向当前程序及 data，未将普通启动锁当已安装 lease。
- 固定 pnpm 仍先锁后冻结、offline/ignore-scripts/禁止自动下载；未手写 node_modules 元数据。新 Profile 在封存前准备，再次实际 prepare 不改变五项配置/锁文件，最终控制器检查通过。
- 真实安装/配置/合作租约证据，与合成外部服务的业务 guard 测试分别记录。后者确实加载已安装组件，但不声称运行了真实 App/Host。
- 初次安装脚本 import 多退一级，执行在导入前失败且根不存在；修正后真实安装 exit0，失败日志保留。核验脚本先误用 cordis.desktop.root.yml，再将 include 规范化后的 file URL 当普通路径；两次均为证据脚本断言问题，原日志保留，未改产品/安装快照来适配断言。实际根配置由固定源码与前轮回执证实为 cordis.yml，URL按 fileURLToPath 校验。
- 单元 upstream preparer 使用显式 PUBLIC 边界，测试在封存前采用其产物；不把夹具文件名或模拟配置作为固定 Desktop 的技术事实。实际 Desktop 函数另有本轮检查。

保留限制：没有应用启动/渲染/停止重启证据；没有 OS 级任意 writer 排他或断网证明；外层发行签名、公开许可闭包、产品内结构修订及专业/用户接受仍各自开放。
