# 可变设置与不可变程序准入

准入 v3 仍固定原开发 Home、mode、发行 API/原生模型策略、程序/依赖/锁文件/Cordis/安装 pin 与启动器源码。移除 settings.yaml 全字节哈希绑定，不在启动时自动重新认可发生漂移的程序。
settings.yaml 仍必须位于隔离 Home 的普通文件且不能经 symlink/junction 解析；有效值由 DSH 原生设置 schema 与业务逐操作校验负责。设置更改不是新生成或外传许可；旧开关/地址不覆盖发行固定配置。校验日志不输出设置或凭据内容。
旧准入必须由受控部署一次升级并保留原件，不能静默把 v2 当作 v3。默认 synthetic 与 --s6-ui-check 模式、单 Host、路径隔离和网络配置不变。

验收：正常保存/项目关联后再启动可通过；缺准入、旧版本、错误 Home、缺必要 pin、任一程序哈希漂移或设置路径重解析均拒绝。
