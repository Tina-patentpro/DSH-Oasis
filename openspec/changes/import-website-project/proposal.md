# 工作台内导入网站项目资料
在当前本地 DSH 项目内打开选择弹窗，复用绿洲登录，选择网站项目与正文/文件并显式下载至当前项目根目录。取代此前新建 Workspace 的设计，不跳网站、不改网站、不生成、不自动同步。

Host 为文件/身份/路径的权威边界；Client 不传下载 URL 或保存路径。保留审核与历史运行身份，导入不创建虚假会话/审核结果。原生设置保存项目关联但不伪造服务映射。

2026-10-05 经用户批准采用业务记录链路 V2：folder → project records → inputs 材料/历史正文/输出附件，统一分页及本地筛选；协议、选择快照、流式预算和部分失败见 specs/record-materials/spec.md。旧 /api/files 404 与旧验收记录保留，不再作为当前实现目标，也不宣称其被修复。
