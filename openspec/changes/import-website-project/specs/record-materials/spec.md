# 业务记录材料导入（2026-10-05 V2）

## Requirements
- 只复用 folderlist/folderdetail/projectlist/projectdetail GET 链路与可信附件地址。不调用 /api/files、不自动回退，不改变旧404的历史结论。
- 协议2统一records分页；Host/Client不匹配拒绝，旧内存票据不可续用，旧关联和清单保持。
- 项目owner匹配，详情ID/folder匹配，若user_id存在必须匹配；字段异常不能用默认ID/空数组补齐。
- text/input/output同页本地筛选。最多20记录/页、2并发详情、30秒/请求、60秒/页，认证/归属错误取消待处理读取；其他错误显式partial及记录ID和安全错误码。partial不证明零材料。
- inputs仅结构化文件对象/数组；输出仅已核实的结构化包装和附件字段。不从正文正则搜索URL。位置空洞保留，超过边界拒绝，未知结构明确不支持。
- 稳定key独立于位置；版本冻结地址及相关元数据。变化必须重选，提交旧版本不产生关联/文件写入。复核当前引用不能证明同址原件未替换。
- 客户端不提供URL/path；附件无Bearer、固定HTTPS来源/路径、无重定向/自动重试。流式单件与剩余总预算检查，失败正文读取计预算；文件不覆盖。
- 新清单版本2保存账户/folder/记录/角色/字段和本次字节哈希，导入未审核；旧清单不改写。关联保存与下载结果分别展示，未知提交结果不自动重试。

## Scenarios
- file_url=[null,urlB]与两个file_output对应，urlB不得误配第一个对象。
- 同一条目名称/大小/类型变化、重读列表后提交旧revision：拒绝，不悄然采用新数据。
- 一条详情404而其余可读：明确部分记录未读取；已验证项可选，零文件关联仍经folder复核。
- 认证/归属失败：停止队列，不能保留为可选部分成功页。
- 单项无长度头超过剩余预算：中止读取，不完整缓冲，不写该文件；后续预算不退还。
- 账户/Workspace变化、并发生成、旧票据、旧协议：拒绝；旧文件/审核/关联保护保持。

## 2026-10-06 已批准审计修复
- response/output/outputs已知包装各层的file_url/file_output不因进入data或outputs而丢失；只遍历已知包装路径，不递归搜寻任意对象或正文。
- 别名跳过缺失/null/空白字符串；非空非法值仍显式不支持，不利用其他字段绕过信任/文件名校验。保留位置空洞、去重及同址元数据冲突规则。
- 命名结构化输出的已知文件type支持remote_url/tool_file；输入只支持remote_url。仅ID、未知传输方式及不可信地址不因输出兼容而开放。
- 新项目第1页读取失败后，显式重试仍为该项目第1页；同项目翻页失败不替换此前成功页或自动重试。
