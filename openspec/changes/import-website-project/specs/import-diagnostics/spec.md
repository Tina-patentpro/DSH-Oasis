# 导入请求安全诊断

## Requirements
- Host仅允许返回 endpoint、stage、kind、httpStatus；前三项为固定枚举，状态码为100—599整数。不得包含URL、项目/文件标识、材料、账户凭据、原始响应、异常message/cause。
- RPC出口和Client显示再次白名单化。无安全诊断的旧错误保留通用提示；任意异常不直接透传。
- 请求失败必须区分项目列表/归属、历史列表/详情、项目文件列表/元数据/下载、历史附件；HTTP、网络/传输、超时、JSON、合同、归属分别可辨识。
- 错误分类不重试、不改变GET路径或凭据发送边界、不放宽归属/大小/重定向/写回校验。旧历史列表仍保留其原类别；失败不变为成功空列表。
- 包装内success=false或非true不能被当作成功数据；旧code=0/200响应兼容保留。
- 离线诊断通过不等同生产根因已确定；列表成功后才进入用户指定文件的下载验收。

## Scenarios
- HTTP401/403/404/500：只返回安全状态及阶段，不暴露响应。
- 传输失败、超时、无效JSON、分页字段缺失、项目归属冲突：可辨别，不自动重发。
- 项目详情归属失败：终止，不将尚未发出的文件列表请求标为失败。
- RPC/Client收到多余或无效诊断：舍弃，不显示秘密。
- 切换项目文件列表失败：原历史内容仍标记历史，无自动关联/下载/生成。
